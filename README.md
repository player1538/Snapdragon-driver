# Snapdragon-driver
Estou disponibilizando o meu arquivo pessoal de desenvolvimento de drivers customizados em Vulkan/Zink focados na GPU Adreno 610 (Snapdragon 460) do Moto G10. São versões antigas que usei como base para fazer o source port de Far Cry 1 (NearChuckle) rodar no aparelho.Estou postando essas builds antigas para fins de preservação e estudo.
para também jogar jogos mobile se o seu celular é um moto G10 e você ou tem apenas 610 com Vulcan 1.1 use meu driver mesmo sabendo que ele é um driver experimental ele já consegue rodar um jogo que eu testei
